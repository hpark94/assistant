# A bare note captures one topic

The note skill's scope step said to capture the last self contained topic, and
in the same sentence to write two notes where two unrelated things are worth
keeping. A bare `/note` after a session that settled two topics sent one agent
to the last topic and another to two previews.

A bare `/note` now captures the last topic. Another topic the session produced
is named in one line, unless it was already named, because `global.md` allows
the `notizwuerdig` line once. Arguments naming several topics get the split
named and the one I confirm captured.

## Considered Options

**Two notes, each with its own preview and yes (rejected).** It was the old
wording and keeps nothing worth keeping from being lost. It was rejected because
"worth keeping" is a judgement two agents make differently, and `global.md`
forbids a skill writing on a topic it judged noteworthy itself.

## Consequences

- A second topic costs one more `/note` with its name as the argument.
