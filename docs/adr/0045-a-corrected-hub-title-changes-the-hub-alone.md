# A corrected hub title changes the hub alone

ADR 0031 settled that a corrected hub title renames nothing and names what the
hub and every child should be called. A child's title begins with its hub's
title, so "called" covered two readings: one agent corrected every child's
`title` and `# H1` in the same pass, the other named them and stopped.

A corrected hub title now changes the hub alone. The one line names what the hub
file and every child's title and file should be called, each child is its own
correction, and the renames stay mine.

## Considered Options

**Correcting the children's titles in the same preview (rejected).** It leaves
the titles in agreement at once. It was rejected because a hub with twenty
children turns one correction into twenty passages under one yes, and
`global.md` keeps a commanded correction out of another's approval unit.

## Consequences

- ADR 0031 is not edited. This record narrows what the hub's correction reaches.
